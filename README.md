# Nalitchka

Демонстрационный интернет-банк: React + Vite на клиенте, Express + Node.js на сервере. Показывает счета, операции и перевод между собственными счетами. Все суммы и операции учебные; данные хранятся в памяти процесса и сбрасываются при перезапуске. Сервис не выполняет настоящие банковские операции и не имеет авторизации.

## Локальный запуск

Требуется Node.js 20.19+ и npm.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 — лендинг в лаймовой концепции. Демонстрационный личный кабинет находится по адресу http://localhost:5173/app. Vite перенаправляет запросы `/api` на Express по адресу http://localhost:3001.

## Сборка и запуск одним сервером

```bash
npm run check
npm start
```

Откройте http://localhost:3001. Порт сервера можно изменить через переменную `PORT`.

## API

- `GET /api/health` — состояние сервера.
- `GET /api/dashboard` — счета и операции.
- `POST /api/transfers` — перевод между своими счетами: `{ "fromId": "main", "toId": "savings", "amount": 100.25 }`.

## Структура

- `client/` — интерфейс React.
- `server/` — Express API, данные и тесты.

Перед использованием с реальными клиентами необходимы авторизация, постоянная база данных, аудит операций, ограничения запросов и интеграция с банковским процессингом.
